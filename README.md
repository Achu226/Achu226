### 📌 Featured projects

#### 🌱 [AgroBot AI](https://github.com/Achu226/agrobotai): an offline crop doctor for farmers
Photograph a leaf and get the disease, the treatment and when it's safe to spray, in **Tamil and 11 other languages**, with **no internet**.
- **48 diseases across 16 crops** plus a separate **pest model (9 pests, 99.78% held-out accuracy)**, both EfficientNetV2-S
- Calibrated confidence: it says *"not sure, take another photo"* instead of guessing; **Grad-CAM** heatmaps show what the model looked at
- Runs on a laptop or a **₹5,000 Raspberry Pi** (ONNX Runtime); the phone connects over the farm's Wi-Fi

`PyTorch` `FastAPI` `Flutter` `ONNX` `React` `Raspberry Pi`

#### 🤖 [Maya (Ather)](https://github.com/Achu226/ather): a free, local-AI desktop assistant
A Windows assistant that runs **entirely on your own PC**: tasks, reminders, calendar, file search, voice chat, chat with PDFs, image generation and an agent mode.
- Picks a local LLM per question (Qwen models for speed, reasoning or code)
- Voice in and out, "Hey Maya" wake word, screen understanding, study tools (quizzes, flashcards, lecture notes)
- Supports MCP tool servers, and Ollama or any OpenAI-compatible model

`Electron` `JavaScript` `Local LLMs` `MCP`
